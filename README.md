# Zveno releases

Installers for Zveno, the desktop app for running a team of AI coding agents.

Download the latest `Zveno-Setup-<version>.exe` from [Releases](https://github.com/artyd/zveno-releases/releases/latest).

Each release also carries `latest.yml` and a `.sig` file. Zveno checks the Ed25519 signature of every update before it installs it.

This repository holds release files only.
